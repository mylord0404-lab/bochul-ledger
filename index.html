내보내기 · 백업

CSV는 엑셀에서 한글이 깨지지 않도록 UTF-8(BOM) 형식으로 저장됩니다. 아이폰에서는 공유 화면이 뜨면 ‘파일에 저장’ 또는 메일/메시지로 보낼 수 있습니다.

백업 불러오기 (휴대폰 이동 시)

‘합치기’는 현재 기록을 유지하고 백업에만 있는 기록을 추가합니다(같은 기록은 백업 내용으로 갱신). ‘전체 교체’는 현재 기록을 모두 지우고 백업 내용으로 바꿉니다.

아이폰 홈 화면에 추가하는 방법

  1. Safari로 이 페이지를 엽니다. (다른 브라우저 앱이 아닌 Safari)
  2. 화면 아래(또는 위)의 공유 버튼 ⬆︎ 을 누릅니다.
  3. 목록을 내려 ‘홈 화면에 추가’를 누르고, 오른쪽 위 ‘추가’를 누릅니다.
  4. 이후에는 홈 화면의 ‘보철장부’ 아이콘으로 실행하세요. 인터넷이 없어도 작동합니다.

참고: 홈 화면 앱과 Safari 탭은 저장 공간이 서로 분리되어 있습니다. 항상 홈 화면 아이콘으로 사용하세요. Safari 탭에서 입력한 기록은 홈 화면 앱에 보이지 않습니다.

사용 방법

  • 입력: 날짜·이름·보철 내용·치료비·첫 수납액을 입력하고 저장.
  • 분할 납부: 미수/일별/검색 목록에서 환자를 눌러 ‘수납 추가’. 수납 날짜는 진료일과 달라도 됩니다.
  • 일별의 수납 합계는 그날 실제로 받은 금액(이전 진료분 포함)입니다. 치료비·미수 합계는 그날 진료 기록 기준입니다.
  • 기록 수정·삭제는 기록을 눌러 상세 화면에서 할 수 있습니다.
